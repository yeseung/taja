📖 한글 타자 연습 사용 방법

한글 타자연습 시작하기

  1. 처음 연습한다면 기본 자리 모드에서 자음과 모음의 위치를 익혀보세요.
  2. 단어 또는 짧은 문장 모드를 선택하고 연습 시간을 설정합니다.
  3. 연습 시작 버튼을 누르면 시간이 측정됩니다.
  4. 제시되는 문장을 띄어쓰기와 문장부호까지 그대로 입력합니다.
  5. 문장을 완성하면 Enter 또는 다음 문장 버튼으로 계속 진행할 수 있습니다.

타수와 정확 문자 수

한글 한 글자는 여러 자모의 조합으로 만들어집니다. 예를 들어 '한'은 ㅎ·ㅏ·ㄴ을 입력하여 완성됩니다. 이 페이지에서는 정확하게 입력한 한글을 두벌식 자판 입력 수로 환산하여 타수를 계산합니다.

정확 문자/분(CPM)은 실제로 올바르게 입력한 완성 문자 수를 기준으로 계산합니다.

정확도 계산

현재 제시된 문장과 같은 위치에 입력된 글자를 비교합니다. 띄어쓰기와 문장부호도 문자로 계산합니다. 잘못 입력한 뒤 지워서 수정하면 현재 결과에 수정된 내용이 반영됩니다.

한글 조합 입력

한글 입력기의 조합 중간 상태를 바로 오타로 판정하지 않습니다. 한글 조합이 완료된 문자열을 기준으로 채점하기 때문에 일반적인 한글 입력 환경에서도 자연스럽게 연습할 수 있습니다.

직접 입력 모드

직접 입력 모드를 선택하면 원하는 문장을 줄 단위로 등록하여 연습할 수 있습니다. 빈 줄은 자동으로 제외합니다.

❓ 자주 묻는 질문

한글을 조합하는 동안 오타로 표시되나요?

아닙니다. 한글 입력기의 조합이 완료된 문자열을 기준으로 비교합니다.

타수는 다른 타자연습 사이트와 동일한가요?

서비스마다 타수 계산 방법이 조금씩 다를 수 있습니다. 이 페이지는 정확하게 입력한 문자를 두벌식 자모 입력 수로 환산한 값을 사용합니다.
