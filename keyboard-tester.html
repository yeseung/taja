키보드 테스트

키를 누르면 화면의 키보드에서 해당 키가 즉시 강조됩니다. 일반 문자 키, 기능 키, 방향키, 숫자 키패드, 좌우 Shift·Ctrl·Alt 입력을 빠르게 확인할 수 있습니다.

테스트 영역 이 영역을 한 번 클릭한 뒤 키보드를 눌러보세요. 테스트 중에는 화면에 표시된 일부 키의 브라우저 기본 동작을 차단합니다.

event.code -

최근 입력

📖 키보드 테스트 안내

키보드 테스트는 브라우저의 키 입력 이벤트를 이용해 어떤 키가 눌렸는지 확인하는 도구입니다. 특정 키가 화면에서 반응하지 않거나 계속 눌린 상태로 표시된다면 키보드 연결 상태와 운영체제 입력 설정도 함께 확인해 보세요.

어떤 키를 확인할 수 있나요?

문자 키, 숫자 키, F1~F12 기능 키, 방향키, Insert·Home·Page Up 등의 편집 키, 숫자 키패드와 좌우 Shift·Control·Alt·Meta 키를 각각 구분해서 확인할 수 있습니다.

색상 표시 의미

진한 초록색으로 표시되는 키는 현재 누르고 있는 키입니다. 연한 초록색으로 남아 있는 키는 테스트 중 한 번 이상 정상 입력이 감지된 키입니다.

동시 입력 확인

여러 키를 동시에 누르면 현재 눌린 키의 수가 실시간으로 표시됩니다. 게임이나 단축키에서 특정 키 조합이 제대로 인식되는지 간단하게 확인하는 용도로 사용할 수 있습니다.

확인할 수 없는 키

브라우저 또는 운영체제가 먼저 처리하는 일부 단축키, 노트북의 Fn 키와 제조사 전용 특수 키는 웹페이지에서 감지되지 않을 수 있습니다.

🔒 이 페이지는 별도 프로그램 설치 없이 브라우저의 키 입력 이벤트만 확인합니다. 입력된 키 정보는 서버에 저장하거나 전송하지 않습니다. 기록 초기화 버튼을 누르면 현재 화면의 테스트 기록을 지울 수 있습니다.
