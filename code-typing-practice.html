코드 타자연습 사용 방법

화면에 표시되는 프로그래밍 코드를 가능한 정확하고 빠르게 입력하세요.

  • 첫 입력부터 시간이 측정됩니다.
  • CPM은 1분 동안 입력한 문자 수입니다.
  • WPM은 5글자를 한 단어로 계산합니다.
  • 잘못 입력한 문자는 빨간색으로 표시됩니다.
  • 입력창에서 Tab 키를 누르면 공백 4칸이 입력됩니다.
  • 코드를 모두 입력하면 자동으로 종료됩니다.
